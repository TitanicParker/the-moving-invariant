# Future state

This document lets the project grow without losing its present research object.

## Languages
Begin with a deliberately small, well-documented multilingual pilot; expand only when adequate translation/resolution competence or tooling is available. Future: additional language families, sign languages, low-resource languages, historical corpora.

## Modalities
Speech; writing; theorem/proof representation; human↔machine representation; later nonlinguistic cognition where evidence permits.

## Creolization cases
Empty initial registry plus literature-backed case templates. Do not fabricate historical linguistic evidence.

## Model families
Record actual model names/versions at experiment time. Never write a model label from memory if it can be queried or recorded directly.

## Domains
Law, science, history, education, mathematics, AI, translation and institutional knowledge as future application/testing domains, not proof.

None currently demonstrated in this repository. The registry remains open.
