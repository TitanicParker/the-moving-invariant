```markdown
# The Moving Invariant

**What survives when expression changes?**

A public research laboratory on the invariance of completed intelligibility across language, representation, history and machine mediation.

## Source lineage
- Persistence — mature Constraint Grammar: https://github.com/TitanicParker/persistence
- Ten-Year-Old — structureacy, Goldmine, Pixels corpus and transfer: https://github.com/TitanicParker/ten-year-old
- The First Opening — historical/methodological lineage where relevant: https://github.com/TitanicParker/The-first-opening

## Previous achievement
The mature grammar proposes six Transformation Patterns × three Completion Topologies × three Persistence Modes = 54 coordinate positions. The dimensions constrain one completion-event simultaneously; the coordinate is not three detachable features.

## The new fuse
The project moves from **What are the forms?** to **What survives when the form is carried through transformation?** The immediate triangulation is stacking, translation and creolization-as-carrying-pressure, extended by theorem→sentence and human↔machine representation tests.

## Three founding experiments
1. Surface divergence / structural recurrence.
2. Coordinate preservation under translation.
3. Context-carried vs linguistically carried intelligibility.

Machine round trips and coordinate-boundary tests are also seeded as complete protocols.

## Universality operating rule
Proceed under the strongest architecture currently earned. A genuine challenge must produce a missing primitive, axis failure or irreducible completed-unit remainder. “There could always be more” is not itself evidence. See `docs/UNIVERSALITY.md`.

## Current research state
- 5 experiments proposed
- 7 future experiment placeholders
- 0 running
- 0 completed
- 0 observed results
- 0 primitive challenges
- 1 small, clearly provenanced Pixels corpus sample
- translation demo schema only; no fabricated multilingual result

## Run locally
```bash
npm install
npm run validate
npm run dev
```

## Build
```bash
npm run check
```

In restricted environments without package-network access, `npm run build:offline` generates a dependency-free static verification snapshot. GitHub Actions runs the real Astro build.

## Add an experiment
Add the research page, then add a unique machine-readable record to `data/experiments.json`. If the experiment yields data, write results separately to `data/results.json` with evidence label and provenance. Never upgrade a protocol or interpretation into `OBSERVED`.

## Deploy GitHub Pages
Push to `main`; `.github/workflows/deploy-pages.yml` installs dependencies, validates data, builds Astro, uploads the static artifact and deploys Pages.
```

## FILE: `docs/UNIVERSALITY.md`

Flat filename: `docs__UNIVERSALITY.md`

```markdown
# Universality operating position

## The claim
The 54 are being tested as a finite universal grammar of completed intelligibility at a specified grain.

## Why finitude is not suspicious by itself
Infinite realizations can arise from finite generative structure. Surface variety does not by itself imply an open-ended primitive inventory.

## What universality means here
Not enumeration of every possible sentence. The hypothesis is structural exhaustiveness of the primitive dimensions: every completed intelligible unit at the chosen grain must answer the three coordinate questions.

## What would defeat the claim
A genuine missing primitive; failure of an axis; failure of independence/exhaustiveness; or an irreducible completed-unit remainder after domain, grain and instrument errors are controlled.

## What does not defeat the claim
Subtype, mechanism, semantic world, grammatical construction, lexical novelty, plurality, negation, purpose, agent, consequence, or the abstract possibility of “more.”

## Why endless hesitation is a liability
If an unobserved possible primitive automatically outranks the current architecture, the theory cannot generate predictions or encounter the severe tests that could falsify it.

## Operating rule
> Proceed as though the strongest currently earned architecture is real enough to generate consequences. Preserve every route by which reality can prove otherwise.
```

# Literature notes — foundation registry

This is a starting bibliography, not a claim that the literature supports the 54.

- **APiCS Online** — expert-based comparative information on 130 grammatical and lexical features across 76 pidgin and creole languages. Useful as a broad structural and language registry. https://apics-online.info/about
- **Mufwene (2022), “Linguistic Hybridization in the Emergence of Creoles”** — treats creole emergence through language contact and hybridization, useful against simplistic single-path narratives. https://www.cambridge.org/core/journals/cambridge-journal-of-postcolonial-literary-inquiry/article/linguistic-hybridization-in-the-emergence-of-creoles/BE56AA2BC8500F428DD860041059FC26
- **Lim & Ansaldo (2015), “Contact and creole formation”** — surveys competing theoretical positions including nativization, substrate influence and broader contact-language formation approaches. https://www.cambridge.org/core/books/languages-in-contact/contact-and-creole-formation/AADEBA34D3AA30C7CAF84F44960E65BF

Future cases must be literature-led and source-specific.

2. Withhold canonical names, canonical utterances, source sentences, and intended answers.

<BaseLayout title="Manifesto — The Moving Invariant">
<section class="hero"><div class="eyebrow">Founding essay</div><h1>The Moving Invariant</h1><p class="lede">What survives when expression changes?</p></section>
<article class="research-copy">
<h2>1. The object before the move</h2><p>The mature Constraint Grammar of Completed Intelligibility begins from structured unresolvedness. Something is not yet determinate enough for stable uptake. A completion answers that opening sufficiently for something to be inherited. This is not truth, certainty, finality, sentence-ending, or a general theory of everything a sentence is about. False, fictional, rejected and revisable units can still complete intelligibly enough to be understood, evaluated, rejected or carried forward.</p><p>The grammar distinguishes three primitive dimensions. Transformation Pattern asks what kind of unresolvedness changed. Completion Topology asks what structural condition made that change count as enough. Persistence Mode asks how the achieved completion remains available afterward. Six transformations, three topologies and three persistence modes yield 54 coordinate positions.</p><p>But the coordinate is not a bundle of three separately recognizable tags. Transformation is this transformation through this topology in this persistence; topology is the topology of this transformation in this persistence; persistence is the persistence of this transformation through this topology. Dimensional Conjunction is reciprocal constraint. The generated object is one completed form.</p>
<h2>2. The sentence is a receipt</h2><p>Sentences remain privileged because they are finite, shareable, repeatable, externally inspectable, translatable, storable, contestable and inheritable. But they are an observational surface, not the ontology. The object is the completed intelligible unit: a local answering of structured unresolvedness that becomes determinate enough for uptake and inheritance.</p><p>This shift matters because it prevents the research from mistaking English syntax, lexical cues, grammatical constructions, institutional context or real-world causation for the coordinate itself. Language may be one of the great public carriers and receipts of completed intelligibility rather than its source.</p>
<h2>3. Why same-cell stacking changed the interpretation</h2><p>Goldmine introduced a severe procedure: give an independent generator only the primitive definitions, Dimensional Conjunction and the coordinate under test. Withhold canonical names, canonical utterances, source sentences and intended answers. Ask the coordinate to generate ordinary companion utterances.</p><p>When utterances from one coordinate are stacked, vocabulary can change, subject matter can change, scenes and agents can change, and grammatical surface can change while a structural family remains recoverable. Stacking therefore stops being merely illustrative. It becomes an invariance assay under lexical and situational variation.</p><p>The inherited lesson is equally important: a sentence is not evidence merely because it was generated for a cell. First-pass false positives occurred. Destructive audit rejected weak crystallizations while holding the grammar fixed. Examples changed to satisfy the architecture; the architecture was not changed to save the examples.</p>
<h2>4. Translation raises the stakes</h2><p>Translation changes more than wording. Languages differ in word order, morphology, tense and aspect, articles, case, gender, evidentiality, subject expression, lexical segmentation, pragmatic burden, idiom, prosody and discourse convention. The question is therefore not whether the same words survive, whether grammar is parallel, or whether every semantic nuance is identical.</p><p class="quote">Did the completed intelligibility preserve its structural coordinate across linguistic realization?</p><p>A rigorous assay freezes the source unit, resolves it structurally, translates independently, hides the source coordinate from the target resolver, freezes the target resolution and compares only afterward. Agreement and disagreement are both data. Divergence may reflect translation drift, source ambiguity, target ambiguity, genuine structural non-equivalence, instrument failure or a problem in the grammar.</p>
<h2>5. Creolization asks a different historical question</h2><p>The programme does not treat pidgins as defective languages, does not assume a universal creole ladder, and does not claim creolization proves the 54. The hypothesis concerns communicative carrying pressure. Immediate context, gesture, shared activity and interlocutor knowledge can shoulder distinctions that an expression leaves underspecified. But when a linguistic system must carry more of a community's life across absence, memory, childhood, narrative, obligation, disagreement, planning and generations, some distinctions may become increasingly expensive to leave wholly to context.</p><p>The surface response may appear through grammar, lexicon, aspect, tense, particles, word order, prosody or discourse convention. The proposed invariant lies beneath the variation. This is a research question that must be constrained by real historical and linguistic scholarship.</p>
<h2>6. Theorem → sentence and representation → representation</h2><p>The larger lineage repeatedly returns to preservation through transformation: a geometric relation surviving movement, a proof step surviving representation, clarification recurring across theorem passages, formal material de-specializing into ordinary language, a completion landing in another intelligence, a coordinate regenerating an utterance, and machine representations round-tripping toward intelligible form.</p><p>The repeated question was already present before it was named: what survives the move?</p>
<h2>7. GPT is not a neutral window</h2><p>Fluent models can contaminate the measurement. Meaning balloon imports causes, institutions, agents, consequences and possible worlds. Construction-level error classifies generic facts about sentences. Semantic dominance lets negation, effect, relation or plurality swallow the coordinate. Agenda drift turns a measurement task into theory redesign.</p><p>Information partition is therefore methodological, not bureaucratic. Blind Assay sees the unit but not the intended coordinate. Structural Decoder receives frozen evidence and the primitive grammar. Coordinate-Only Deriver receives the coordinate and grammar but not the source. Coordinator compares only after the independent outputs are frozen.</p>
<h2>8. Invariance requires boundaries</h2><p>Vague sameness cannot support a science of persistence. The programme therefore asks two complementary questions. What transformations can expression undergo while completed intelligibility remains structurally unchanged? What is the smallest change sufficient to move it into another coordinate?</p><p>Neighbor tests matter because a useful invariant must have a transition boundary. Experiment 005 deliberately holds two axes fixed, moves one, and asks for the smallest ordinary-language change that produces the neighbor.</p>
<h2>9. What would count as a real failure?</h2><p>The 54 are being used as the strongest currently earned coordinate grammar. A genuine counterexample must produce a locally completed intelligible unit requiring a seventh irreducible Transformation Pattern, a fourth irreducible Completion Topology, a fourth irreducible Persistence Mode, a demonstration that the axes are not independent or exhaustive as claimed, or an irreducible completed-unit remainder after domain, grain and instrument errors have been controlled.</p><p>Subtype, mechanism, semantic world, grammatical construction, plurality, negation, purpose, agent, consequence and lexical novelty do not defeat the grammar merely by being additional detail. The burden is structural: show the missing primitive or show the irreducible remainder.</p>
<h2>10. Why permanent hesitation is not neutrality</h2><p>A finite grammar can generate indefinitely many expressions. Infinite manifestation does not imply an infinite primitive inventory. Saying “perhaps there is always a 55th” is not itself an argument. If hypothetical unobserved primitives are allowed to outrank every earned structure, the theory can never generate strong predictions, attempt severe invariance tests or encounter the failures that would make revision informative.</p><p class="quote">Proceed under the strongest architecture currently earned. Commit enough to let the structure answer, and remain open enough to let a real remainder defeat it.</p>
<h2>11. The new research object</h2><p>The question is no longer whether different expressions can be placed in the same cell after interpretation. The question is whether a completed form remains invariant while the expression that carries it changes.</p><p>If the 54 are artifacts of English wording, canonical vocabulary or prompt conditioning, sufficient transformation should pull them apart. If they belong to completed intelligibility itself, the prediction is surface divergence with structural recurrence.</p><p>Language may be one of the great carriers of the structure rather than its source. A hypothetical missing primitive does not outrank the structure already earned. The way to challenge the grammar is to produce the remainder.</p>
<h2>12. The declaration</h2><p>We are no longer asking only whether completed intelligibility can be classified. We are asking whether it can move.</p><p>Change the words. Change the language. Change the context. Change the representational system.</p><p>If the structure is real, some transformations should leave it invariant. Others should move it across a boundary. This repository exists to find the difference.</p>
