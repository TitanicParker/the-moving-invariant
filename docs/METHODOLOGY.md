# Methodology

Lock the unit. Ask what completed here. Do not import the world. Preserve Dimensional Conjunction. Separate epistemic roles when fluency contaminates measurement. Freeze first, compare later, preserve disagreement, use neighbor tests, keep failure first-class, and let a genuine structural remainder force revision.

## The relation is part of the method

The repository is not a substitute for the originator. At conceptual thresholds, return the machine's current understanding to the originator, let disagreement expose drift, reconcile the object, and only then allow the next major claim to inherit authority.

This is not founder authority. The originator can be wrong. The machine can be wrong. Neither mirror wins by identity. The relation is valuable because different intelligences can pressure the same object.
